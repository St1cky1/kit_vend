# Repository Information: Kit Vending Backend

## 📝 Обзор проекта
**Kit Vending** — это бэкенд-сервис, построенный на языке Go, предназначенный для управления торговыми автоматами. Он обеспечивает интеграцию с внешним API Kit Vending и предоставляет собственный gRPC/REST интерфейс для мониторинга и управления (продажи, события, состояние оборудования, команды).

## 🛠 Технологический стек
- **Язык**: Go 1.25.4
- **Коммуникация**: 
  - **gRPC**: Основной протокол взаимодействия.
  - **gRPC Gateway**: REST API прокси.
  - **Protobuf**: Описание контрактов (v1).
- **База данных**: PostgreSQL 18 (Docker).
- **Архитектура**: Clean Architecture (Слои: Entity -> Use Case -> Transport/Storage).
- **Инструментарий**: 
  - `Makefile` для автоматизации.
  - `Docker` & `Docker Compose` для контейнеризации.

## 📂 Структура репозитория
```text
.
├── cmd/server/            # Точка входа (main.go), инициализация сервера

├── pkg/
│   ├── config/            # Загрузка и управление конфигурацией (.env)
│   ├── constants/         # Общие константы проекта
│   ├── logger/            # Настройка логирования
│   └── pb1/               # Сгенерированный Go-код из protobuf
├── docs/                  # Документация (API.md, PDF)

```

## 🏗 Ключевые компоненты

### 1. Доменные сущности (`internal/entity/`)
- **VendingMachine**: Описание автомата, его состояния и остатков.
- **Courier**: Сущности для управления процессом загрузки товаров (ячейки, сессии загрузки).

### 2. Бизнес-логика (`internal/usecase/`)
- **vending_machine.go**: Логика получения данных об автоматах, продажах и отправки команд.
- **courier.go**: Логика процесса обслуживания автомата курьером (MVP загрузки).

### 3. Транспортный слой (`internal/grpc/`)
- Реализует gRPC методы, которые затем проксируются в REST через `grpc-gateway`.

## 🚀 Команды разработки
| Команда | Описание |
| :--- | :--- |
| `make proto` | Генерация Go-кода из `.proto` файлов |
| `make build` | Сборка бинарного файла в `bin/server` |
| `make dev` | Запуск сервера в режиме разработки с автоперезагрузкой |
| `make test` | Запуск юнит-тестов |
| `make lint` | Проверка кода линтером |

## 🔗 Основные эндпоинты (REST)
- `GET /api/v1/vending-machines/{id}` — Инфо об автомате.
- `GET /api/v1/sales` — История продаж.
- `POST /api/v1/commands` — Отправка команд на автомат.
- `POST /api/v1/courier/load-sessions` — Управление сессиями загрузки.
